## 一、核心结论

### 三句话

**第一句：上午不是"普跌"，是"三只股票的定向爆破"。** 创业板指 **−1.47%**，拆开看：中际旭创 **−6.21%**（权重 11.39%）、新易盛 **−6.47%**（5.81%）、天孚通信 **−8.88%**（2.19%），三只合计贡献 **−1.2777pp，占指数全部跌幅的 86.9%**。同一天，宁德时代 +0.12%（第一大权重 14.46%）、迈瑞医疗 +1.50%、汇川技术 +1.15%、东方财富 +0.77%、温氏股份 +1.83%，**其余六只权重股合计 +0.1617pp——它们是净买方。剔除这三只，创业板指只跌 0.19%。**

## 二、板块冷热地图（2×2 · 双重口径降级）

**必须先说降级**：标准 2×2 的两个轴本期一个都没有真数据。

1. 横轴"估值分位"——**板块级 PE/PB 分位序列不存在**，接口只支持指数级估值 → 降级为 **60 日涨跌幅（位置）**；
2. 纵轴"资金方向"——**行业资金流接口连续第七期返回"涨幅榜"**，无任何资金净流入字段 → 降级为 **当日涨跌幅（动量）**；
3. 板块跌幅榜仍不可得，左下格只能用三只个股代理。

**两个替身都不是原口径**：60 日涨跌幅 ≠ 估值分位（跌 60% 的板块可能仍很贵），当日涨跌幅 ≠ 资金净流入（涨可以是缩量涨）。**所有象限结论的置信度因此降一级。**

```
纵轴：当日涨跌幅（资金方向代理）↑
┌─────────────────────────┬─────────────────────────┐
│ 左上 · 低位 + 在涨（4）  │ 右上 · 高位 + 在涨（6）  │
│ 补涨                    │ 高位在加速，不是补跌     │
│ 电视广播 +3.39 / +2.53  │ 数字媒体 +0.60 / +25.38 │
│ 饲料     +2.26 / +1.94  │ 影视院线 +5.09 / +20.95 │
│ 摩托     +1.84 / +0.62  │ 国有大行 +0.96 / +16.89 │
│ 商用车   +1.94 / −10.10 │ 出版     +0.93 / +16.46 │
│                         │ 养殖业   +2.31 / +11.65 │
│                         │ 小家电   +0.48 / +10.86 │
├─────────────────────────┼─────────────────────────┤
│ 左下 · 低位 + 在跌（主角）│ 右下 · 高位 + 在跌        │
│ 定向出清                │ 空 —— 这就是结论         │
│ 光模块三只 −6.2~−8.9    │ 今天没有任何一个"60 日   │
│ 60 日约 −34%            │ 强势板块"在失血          │
└─────────────────────────┴─────────────────────────┘
   ← 60 日跌得多              60 日涨得多 →
```

**四格逐读：**

- **右上（6 只，占满）**：60 日涨幅榜前六今天**全部上涨，无一下跌**。资金不是在撤出高位，是**从 AI 硬件撤进高位红利与低位题材**——两种撤退方向相反，来源同一个：光模块。
- **左上（4 只）**：60 日没怎么涨，今天跟着题材（短剧/猪肉）走。商用车 60 日 −10.10% 今日 +1.94%，是典型跌深反弹。
- **左下（本期主角）**：光模块三只半日成交 **379.19 亿**，在一个缩量 19.82% 的上午放量下跌。**全市场缩量，这三只放量——资金定向撤离，不是市场普跌。**
- **右下（空）**：**空格即结论。** 这轮下跌不是"高位补跌"，是**"单一产业链的定向出清"**。若是前者，下一步会蔓延到所有高位板块、该减仓；若是后者，杀伤被限制在那条链上——**不该因为创业板 −1.47% 就把养殖、医疗、电池一起卖掉。本期倾向前者：右上有 6 只、左上有 4 只、右下为 0。一个"全面补跌"的市场，右下不会空。**

**置信度：中。** 午间板块排名本身是"低可信度"数据。**证伪条件**：若今日收盘或下周一，影视院线 / 数字媒体 / 国有大行这三个"高位且今天在涨"的板块开始下跌（跌幅 >2%），则"单一产业链出清"被证伪，应改判为"高位补跌的第二天"。

## 三、热点与冷门

### 热点 · 三条互不相干的线，同一个共同点

| 线 | 代表 | 读数 | 性质 |
|---|---|---|---|
| **短剧 / 影视** | 影视院线、电视广播、数字媒体、出版 | +5.09% / +3.39% / +0.60% / +0.93% | 唯一"成板块"的题材；换手 7.26%、5.32%，**情绪资金** |
| **猪肉 / 养殖** | 养殖业、饲料、温氏 | +2.31% / +2.26% / +1.83% | 周期底部 + 涨价预期，**防御性进攻** |
| **银行 / 白酒** | 国有大行、招行、茅台、平安 | +0.96% / +0.38% / +1.25% / +0.17% | 纯防御，上证 +0.22% 的主要来源 |

**三条线的共同点：都不需要"高增长故事"就能讲通。** 短剧讲流量，猪肉讲周期，银行讲股息。**在"高增长故事被质疑"的那一天，钱会流向"不需要高增长"的地方。**

### 冷门 · 拆成两义，本期只识别出一种

**资金冷：光模块 / 元件。** 今天 −6.2% 到 −8.9%，60 日约 −34%，三只半日成交 379.19 亿。**它是"资金冷"，但估值冷不冷？** 前瞻 PE 16.30 倍看起来不贵，可 PCF 25.27、**PE/PCF 1.106**——现金流匹配度极差。**所以它是"资金冷 + 现金流未验证"，不是"估值冷"。**

**估值冷：本期识别不出。** 没有板块级估值分位序列，**任何"某板块估值处于历史低位"的说法在本期都是无据的。** 不做判断，不插值。

**"找不到"本身是一个结论**：当所有低位板块（电视广播、饲料、摩托、商用车）今天都在涨，说明**"低位"这个属性今天被资金全面买入了**——一个被全面买入的低位，不再是冷门，是补涨。**真正冷的（光模块）不便宜，便宜的（低位补涨）不冷了。这就是当下的市场状态：没有"又冷又便宜"的地方。**

> 方法论原话：**资金冷是现象，估值冷是资格。** 两者都冷才是机会，只有资金冷是陷阱。本期两者不重叠，故不给"冷门机会"结论。

## 四、龙头点评（A / B / C 三类）

**分类标准写死**：A 类 = 逻辑成立、现金流已验证（经营现金流/净利 ≥0.8，PE/PCF ≤1.5）；B 类 = 逻辑成立、现金流**未**验证；C 类 = 逻辑存疑或已证伪。**股价不能给基本面定罪——把 B 类降为 C 类需要财报证据，不能靠三天股价。**

### A 类 · 宁德时代 / 迈瑞医疗 / 汇川技术 / 东方财富

合计权重 **25.09%**，今日 +0.12% / +1.50% / +1.15% / +0.77%，合计贡献 **+0.128pp**。

- **今天的作用**：宁德时代 14.46% 权重贡献 +0.0174pp，是最大的稳定器。**若它也跌 2%，指数会多跌 0.29pp、变成 −1.76%。**

- **该等什么**：等四季报毛利率与储能订单；迈瑞、汇川等估值分位回到 30% 以下再看性价比。
- **一条提醒**：券商在缩量 19.82% 的市里上涨，是**预期交易**（赌后面的量回来），不是业绩交易。**不该把"券商涨"当"牛市来了"。**

## 五、短期与长期方向

**短期问边际**（在 10.5% 上要不要再加）；**长期问存量**（9% 底仓该不该有）。**混成一句话就变成"既看好又不买"；分开写则自洽：存量合理，增量差一步。**

### 短期 1–4 周 · 只回答"动不动手"

**结论：不动。不加，也不减。** 底仓 9% + 弹性仓 1.5% = **10.5%**，本周不调仓。

| 触发项 | 阈值 | 当前 | 距离 |
|---|---:|---:|---|
| **赔率（中枢）** | **≥1.2:1** | **1.31:1** | **✓ 已达成** |
| P0 资格线 | ≤2,400 | 2,472.53 | **−2.93%** |
| ERP +1σ（沪深300） | 3,549 | 4,042.05 | −12.19% |
| 融资余额红线 | ≤22,550 亿 | 22,731.28 亿（11-11） | +181.28 亿 |
| 跌停占比 | ≥0.30% | 0.143% | 极远 |

- **加仓条件第一次 1/2**：赔率 1.31 ≥ 1.2 ✓；P0 未到 ✗。**这是本轮下跌以来两个条件第一次只剩一个。**
- **但"只差一个"不等于"快到了"**：2.93% 一天就能走完（今日振幅 2.50%）。**必须预先写死：到 P0 当日跌停家数 ≤20 家才动手。在恐慌中接刀，不是纪律，是赌博。**
- **到了 P0 也不是满仓**：标称 2% × k_T 0.75 × k_L 0.5 × k_V 1.0 = **实际 0.75pp**，弹性仓 1.5% → **2.25%**。k_L 取 0.5 的理由：逻辑未失效（不是 0），但未确认（不是 1）。
- **为什么还不加**：① P0 未到；② 宽度 41.92%，与昨天 42.03% 几乎一样，**不是加仓环境**；③ 缩量 + 跌停 1→8，**承接不足**。
- **为什么还不减**：① 逻辑失效 9 条触发 **0 条**；② 沪深300 在 μ 下方 2.15%，未到"不便宜"；③ 跌停占比 0.143%，远低于 0.30%，**有恐慌但无流动性踩踏**。

### 长期 1–3 年 · 只回答"买什么、买多少"

**结论：结构不变。** 底仓 9% 沪深300，弹性仓上限 10%（现 1.5%）。合计硬上限 **22%**，当前 **10.5%**，等效单一标的 **11.1%**，σ_p **3.98%**。

```
创业板指 σ ≈ 36%，沪深300 σ ≈ 39%，ρ ≈ 0.86
w1 = 1.5%（弹性仓）  w2 = 9.0%（底仓）
σ_p = sqrt((0.015×0.36)² + (0.09×0.39)² + 2×0.015×0.09×0.36×0.39×0.86) = 3.98%
等效单一标的仓位 = 11.1%
```

- **底仓为什么是沪深300**：① 风险预算（创业板指 60 日区间 −25.57%，尾部更厚）；② 沪深300 **缺口 +44.0pp**（PE 分位 74.09% vs PB 分位 30.12%），贵在盈利被压，可靠 ROE 修复消掉；③ 股息率 2.83% vs 10Y 1.6032%，**利差 +123bp，有票息托底**。
- **本期关键修正**：创业板指缺口 **−10.0pp**，是"真便宜"；但它的便宜依赖一个 **14.04% 的 ROE**（六指数最高）。**真便宜 + 高依赖 = 高弹性 + 高脆弱**，这正是它只配 1.5% 的原因。它的股息率 1.23%，**息债差 −38bp，负的，没有托底**。
- **弹性仓为什么只 1.5%**：档位由 ERP 的 σ 位置决定，不由"觉得便宜"决定（z = +0.13σ → 底仓 9%）。创业板资格挂在 P0（2,400），**未到就是未到**。
- **最大的下行风险**：μ 若取 6.00% 而非 5.68%，z 从 **+0.13σ 掉到 −0.14σ**，底仓从 9% 降至 **6%**。**同一个市场、同一个价格，换一个均值假设，差 3 个百分点。**

> **长期最该记住的一句**：「便宜」决定「买不买」，「波动」决定「买多少」，**「现金流的确定性」决定「敢不敢重仓」**。光模块三只 PE 不高、增速不低，但现金流未验证——**所以它们连"敢重仓"的门槛都没过，与价格无关。**
