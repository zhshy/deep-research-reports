## 核心结论摘要

**三句话**：

**第一，收盘把上午的负期望抹平了，但只抹平到 1.00:1。** 六大指数全线上涨（上证 +0.10%、沪深300 +0.29%、创业板指 +0.87%、科创50 +1.68%），但**没有一个收在午间点位之上**——除上证高出 0.12 点、等于没动，其余全部低于 11:30。创业板指从上午 2,576.28 回落到 2,566.80（−0.37%），概率加权期望收益因此从 −0.31% 回到 **+0.06%**，赔率从 0.98:1 回到 **1.00:1**。**这不是"变便宜了"，这是"回到零优势"。**

**第二，指数在让，宽度在扩，钱没有多来。** 上涨家数从上午 4,792 增到 **4,869**（占比 87.29%），涨停从 62 家增到 **86 家**，跌停 0 家——宽度是两个月来最健康的一天。但成交额 21,179.50 亿里，**上午 14,643.73 亿、午后只有 6,535.77 亿（上午的 44.6%）**。**上午是脉冲，午后是消化；权重让位给个股，增量资金没有接力。**

**第三，八项判据一分未动。** 因为它的数据源全部是季度财报或 T-1 数据，**收盘只改变价格，不改变判据**。总分仍是 **+0.100**（已实现层 +0.200、前瞻层 −0.100），底仓目标仍是 **9%**（沪深300 ERP 5.71%、z **+0.03σ**）。**今天的全部变化都发生在报价上，没有一处发生在报表上——这就是"什么都没发生"的精确含义。**

### 三个反直觉的发现

**发现一：指数收绿变红的过程里，最该涨的那只票跌了。**

科创50 全天 **+1.68%**，是六大指数里最强的。但同一天，全市场**融资净买入额第一**的个股是寒武纪，净买入 **6.53 亿元**——它收 **−0.31%**，盘中最高冲到 +4.04%（881.88 元），然后一路往下，收在 845.00 元。

**融资买得最多，股价收跌。** 这两个事实放在一起，只有一种解释：**有人在用融资盘接货，同时有人在用现货出货，而出货的量更大。** 融资盘是"借钱看多"的钱，它的方向不代表价格的方向——它只代表"有人愿意付利息赌这一把"。

对比一下同一天的另一组：中微公司融资净买入没有进前五，收 **+5.83%**。**"借钱最多的"和"涨得最好的"，不是同一批股票。** 这是本期最值得记住的一组对照：**杠杆资金的流量，是情绪的计量器，不是价格的预测器。**

**发现二：本期的"冷门"只有一个，而它不便宜——所以候选池是空的。**

按方法论，冷门要拆成两个词：**资金冷是现象，估值冷是资格。** 今天 12 个可观察板块里有 11 个 5 日为正，唯一"资金冷"的是**国有大型银行**（今日 −0.72%、5 日 −4.38%、60 日 +14.55%）。

但它冷，不是因为便宜。用上证50 作估值代理（银行是它的第一权重），**PE 5 年分位 94.64%**——接近五年最贵的 5%。**一个 60 日涨了 14.55%、估值分位 94.64% 的板块在下跌，这不叫"冷门"，这叫"拥挤之后的退潮"。**

所以本期的候选池仍然是空的。**空的原因不是"没找到冷门"，而是"唯一的冷门不便宜"。** 这两句话听起来一样，含义完全不同：前者是能力问题，后者是市场状态。**今天是后者——这一轮反弹已经把"便宜且无人问"的角落买掉了。**

**发现三：上午领涨的是"硬资产"，午后换棒给了"软内容"。**

上午涨幅前六：光伏设备 +7.08%、能源金属 +5.66%、贵金属 +5.31%、电池 +4.97%、广告营销 +4.69%、装修装饰 +4.54%。**五个是资源与制造。**

收盘涨幅前六：光伏设备 +6.23%、**数字媒体 +5.41%**、能源金属 +5.35%、贵金属 +5.19%、广告营销 +5.12%、**影视院线 +4.75%**。**两个新面孔都是传媒。**

更关键的是把整个传媒链拉出来看：数字媒体（5 日 +13.87%、20 日 +24.55%、60 日 +21.91%、年初至今 +8.34%）、影视院线（+10.00% / +18.94% / +15.14% / −6.99%）、广告营销（+9.54% / +11.10% / −4.29% / −8.62%）、出版（+5.92% / +14.39% / +12.52% / +4.39%）。**四个子行业，5 日、20 日、60 日三个尺度几乎全部为正。**

这是**本期唯一一条"三尺度同向 + 产业链同步"的线索**。而上午的前六里，一个传媒都没有。

**还有一个提前一天的证据**：11-04 的两融数据里，**融资净买入居首的行业就是传媒（+4.27 亿元）**，其次是电力设备、计算机（各 +3.91 亿）。**杠杆资金的行业配置，比价格早了一天。** 这不是巧合能解释的量级——它是本期唯一"资金先行、价格后到"的样本。

**这张表有三件事必须连起来看。**

**第一，涨幅的排序仍然是"久期"的排序。** 从科创50 的 +1.68%，到深成指的 +1.19%、创业板指的 +0.87%、沪深300 的 +0.29%，再到上证的 +0.10%、上证50 的 +0.09%——**一路递减，和现金流回收期的长短完全同序**。上午这个排序就成立，收盘依然成立。**一天走完，风格没有切换，只是强度衰减了。**

**第二，没有一个指数收在午间之上。** 除上证高出 0.12 点（+0.003%，等于没动），其余五个全部低于 11:30 的点位：沪深300 −0.06%、深成指 −0.24%、创业板指 −0.37%、科创50 −0.42%。**"上午的高点区就是当日的阻力区"——这句话在收盘得到了当天最直接的证据。**

**第三，回吐的幅度与"久期"同序，方向相反。** 距当日最高点：科创50 **−3.19%**、创业板指 **−2.25%**、深成指 −1.23%、沪深300 −0.57%、上证 −0.32%。**久期越长，从最高点回吐得越多。** 这不是随机噪声，这是"高久期资产的定价更依赖情绪，情绪退潮时回撤更深"的日常演示。

**这三个事实合起来说的是同一句话：今天上涨的燃眉之力在上午用完，午后是消化，不是接力。**

**指数在回落，宽度在扩大——这是今天最反直觉的一组数据。**

四个指数低于午间，但上涨家数从 4,792 增到 4,869（+77 家），涨停从 62 家增到 86 家（+24 家），跌停仍然是 0。**换句话说：下午有更多的股票在涨，但指数在跌。**

这在数学上只有一种可能：**权重股在跌，小票在涨。** 上证50 +0.09% 看起来是红的，但它的第一权重行业——国有大型银行——收了 **−0.72%**。**指数的"红"是平均数，宽度的"扩"是分布。当两者背离时，宽度更接近大多数人的账户体验。**

涨跌幅分布也印证这一点：涨停 86 家、+7% 以上 178 家、+5%~+7% 327 家、+2%~+5% **2,226 家**、0~+2% 2,052 家；下跌侧 −2%~0 466 家、−5%~−2% 115 家、−7%~−5% 27 家、−7% 以下 17 家、跌停 0 家。**右侧的厚度（2,226 家在 +2%~+5%）远大于左侧（115 家在 −5%~−2%），这是一个右偏的分布。**

**但宽度好，不等于可以买。** 宽度回答"今天赚钱的人多不多"，不回答"明天还能不能赚"。**87.29% 的上涨占比，是"情绪修复"的证据，不是"估值便宜"的证据**——后者才是仓位该看的东西（见第三章、第六章）。

### 1.3 成交：全天 2.12 万亿，但午后只有上午的 44.6%

| 指标 | 数值 | 对比 |
|---|---:|---|
| 两市全天成交 | **21,179.50 亿元** | 较昨日 20,376.92 亿 **+802.58 亿（+3.94%）** |
| 沪市 | 9,797.12 亿元 | — |
| 深市 | 11,382.38 亿元 | — |
| 上午（11:30 前） | 14,643.73 亿元 | 占全天 **69.1%** |
| **午后（13:00–15:00）** | **6,535.77 亿元** | **仅为上午的 44.6%** |

**这是本期最重要的一张表，因为它推翻了"放量"这个说法的朴素读法。**

上午半日成交 14,643.73 亿，同比昨日同期 +58.30%。如果线性外推，全天应该是 2.9 万亿。**实际只有 2.12 万亿——午后只成交了 6,536 亿，不到上午的一半。**

对比一下量比：上证全天的量比只有 **1.08**（上午还是 1.44），创业板 1.15，沪深300 1.10。**量比是"当日累计量 ÷ 过去 5 日同期均量"，它在一天之内从 1.44 掉到 1.08，只说明一件事：下午几乎没人交易。**

**所以"放量"这个判断，必须分成两句说：**

- **总量上，是放量的**：2.12 万亿 vs 昨日 2.04 万亿，+3.94%，是实打实的增加。
- **结构上，是脉冲的**：69.1% 的成交量集中在上午三个半小时，午后是"高开低走 + 缩量"的典型组合。

**为什么这个区分重要？** 因为在方法论里，"低位放量"是承接，"高位放量"是换手。今天的位置是"两天涨了 7% 之后、沪深300 已到 ERP 公允线附近"——**所以这是高位。高位放量 + 午后缩量，标准的读法是"上午有人卖，下午没人接"。**

**这个读法在收盘被验证了一半**：指数确实没有再往上走，但也没有崩——创业板指收在 2,566.80，全天仍涨 0.87%。**所以更精确的表述是"派发未完成、承接也未崩溃"——一个双方都不满意的收盘。**

### 1.4 一天的路径：上午冲高、午后阴跌、尾盘小幅回抽

**今天走的是"低开—冲高—回落—横盘"的路径，不是"单边上涨"。**

三个指数都在上午十点前后见到全天最高，然后一路阴跌到收盘。创业板指从 +3.19% 掉到 +0.87%，**回吐了 2.32 个百分点**；科创50 从 +5.03% 掉到 +1.68%，**回吐 3.35 个百分点**。

**这条路径的含义，比收盘的涨跌幅重要得多。** 因为收盘涨跌只告诉你"结果"，路径告诉你"过程里谁在卖"。**一个从 +3.19% 掉到 +0.87% 的指数，说明在 2,600 点上方有持续的、不间断的卖盘**——不是一次性砸盘（那会留下长下影），而是**一路阴跌（这留下的是上影线 + 实体阴线）**。

**下午的"阴跌"比"暴跌"更值得警惕。** 暴跌会引出抄底盘，阴跌只会引出更多的止损盘。

### 1.5 本章留下的张力

收盘的画面是"指数小涨、宽度扩大、成交缩量"——三个词分别指向三种解释：情绪还在（宽度）、资金撤了（缩量）、权重被弃（指数）。

**如果情绪还在，为什么资金撤了？如果资金撤了，宽度凭什么扩大？**

这个矛盾不能用情绪回答，只能用"上午那个判断到底对不对"来回答。**而这正是收盘版存在的唯一理由——它必须对账。**

## 第二章 午间判断对账：三条证实、一条修正、两条未决

### 2.1 上午 11:30 那个版本，说了六件可以被检验的事

午间版在 9.7 节列了一张"必须等收盘确认"的表，共六项。**收盘数据现在都在手上，逐条对账。这是收盘版的核心增量，也是它唯一不可替代的地方。**

| # | 午间判断 | 午间设定的检验标准 | 收盘实际 | 结论 |

**三条证实、一条修正、一条判据失效、一条未决。** 下面逐条说清。

### 2.2 第 1 条：遇阻被证实，但"派发"这个词用早了

午间版的原文是："上午的高点已经试探过更高的估值，但没守住。**'冲高回落'在放量背景下，通常意味着上方有实实在在的卖盘**……如果午后再次冲高并守住，性质要从'遇阻'改成'换手'；如果午后继续回落，那么上午的 1.46 万亿就是'派发量'。"

收盘事实：**没有任何一个指数在午后创出新高。** 创业板指午后最高也没越过上午的 2,625.98，收在 2,566.80。

**所以"遇阻"这一半，百分之百证实。**

**但"派发量"这一半，只说对了一半。** 派发的标准形态是"高开低走 + 放量下跌 + 尾盘跳水"。今天的实际形态是"高开低走 + **缩量** + 尾盘小幅回抽"。**缩量下跌不是派发，是"没人接也没人急着卖"。**

**这个区别很重要，因为它决定了下一个动作**：如果是派发，接下来应该减仓；如果是"没人接也没人卖"，接下来应该是等——等哪一边先动。

**我在这里要修正自己上午的措辞**：把"派发量"改成"**未完成的换手**"。理由是成交结构——午后只有 6,536 亿，占全天 30.9%，**这个比例在"派发日"里是偏低的（派发日通常午后放量）**。

### 2.3 第 2 条：那个"0.18% 就会跌破 μ"的警告，没有触发——但它本身有个口径问题

午间版写的是："当前沪深300 是 4,115.93，距离'跌破 μ'的边界 4,123 只剩 +0.17%。**下午只要再涨 0.18%，z 就会重新跌破 μ。**"

收盘 4,113.41，跌了 0.06%，**离 4,123 反而更远了**（现在是 −0.23%）。所以这条警告**没有触发**。

**但这里必须坦白一件事：那条警告里的 4,123，是用 y10 = 1.605% 算出来的。本期换成 1.591% 之后，μ 对应的点位变成 4,131。**

```
μ 点位 = E × 100 / (μ + y10) = 300.36 × 100 / (5.68 + 1.591) = 4,131
```

**同一个 μ，因为 10Y 国债下行了 1.4bp，边界点位从 4,123 抬到了 4,131。** 换句话说：**利率下行会"被动抬高"公允点位——同样的盈利，更低的贴现率，值更多的钱。**

这正好是方法论里"ERP 三个陷阱"的第一条：**低利率会白送 ERP**。今天这 1.4bp，价值 8 个点的沪深300。**量级很小，但方向要说清：利率下行时，"跌破公允"的门槛会自动上移，这不是市场变强了，是折现率变了。**

**收盘的准确位置**：4,113.41 vs 边界 4,131，**低 0.43%**——也就是 z 仍在 μ 上方（+0.03σ），档位仍是 9%。**边界没有被击穿，但距离只有 0.43%，仍在 ±0.5σ 的临界区里。**

### 2.4 第 3 条：负期望被抹平到零期望——这是修正，不是翻转

这是本期最需要精确的一句话。

```
上午：期望点位 2,568.25 / 上午价 2,576.28 − 1 = −0.31%
收盘：期望点位 2,568.25 / 收盘价 2,566.80 − 1 = +0.06%
```

**期望点位一分没变（2,568.25），变的只有价格。** 昨天收盘 2,544.73 时是 +0.92%，上午涨到 2,576.28 变成 −0.31%，收盘回落到 2,566.80 又变成 +0.06%。

**一天之内，这个数字走了三站：+0.92% → −0.31% → +0.06%，而基本面一个字没变。**

**这就是"期望收益"这个指标的真实性质：它把"价格"翻译成"未来的收益率"，所以它天然是一个反着的指标——价格涨，它跌。**

**要不要把"涨出来的负期望"这个判断撤回？不撤，但要降级。** 准确的说法是：

> **上午的价格（2,576.28）确实把期望收益打成了负数；收盘的价格（2,566.80）把它拉回了零附近。"负期望"这个状态存在过 3.5 个小时，但它不是收盘状态。**

**为什么这个区分不是文字游戏**：因为仓位是按收盘价执行的。**上午的 −0.31% 从来没机会被交易，收盘的 +0.06% 才是可执行的数字。** 一个不能被执行的负期望，和一个可以被执行的零期望，是两件事。

**赔率同理**：中枢口径从 0.98:1 回到 **1.00:1**，尾部口径从 1.08:1 到 **1.10:1**。**回到 1:1 的意思是——向上和向下的空间一样大。一样大，就是没有优势。**

### 2.5 第 4 条：2.12 万亿落在"中间带"，说明这个判据设计得不好

午间版设的阈值是："全天 ≥2.2 万亿 → 放量确认；<1.8 万亿 → 上午是脉冲。"

实际 2.12 万亿。**落在两个阈值之间的空档里，判据失效。**

**这不是数据的问题，是判据设计的问题。** 一个只能给出"是/否"、却在中间地带失语的判据，等于没有判据。**本期把它修掉：不看总量，看结构。**

```
结构判据（本期新增）：
午后成交 / 上午成交 = 6,535.77 / 14,643.73 = 44.6%
→ 若 ≥80%：全天匀速，承接充分
→ 若 60%~80%：正常衰减
→ 若 <60%：脉冲式放量，午后无接力
本期 44.6% → 明确落在"脉冲"区间
```

**为什么用比值而不是绝对值？** 因为绝对值受"当天总成交量"影响，而比值只受"日内节奏"影响。**总量回答"今天有多少钱进来"，比值回答"这些钱是什么时候进来的"。后者才是判断"承接还是派发"的关键。**

**本期结论：脉冲式放量。** 上午的钱是"抢反弹"的钱，午后的缩量说明抢完之后没有第二批。

### 2.6 第 5 条：涨停 86 家，中性偏正

午间的标准是">100 家 → 情绪强；<60 家 → 上午已透支"。收盘 86 家，从上午的 62 家净增 24 家。

**这个数字单独看是中性的，但配上一个数据就变成偏正**：昨日（11-04）涨停的 122 只个股，今天有 **81.15% 上涨**。**这说明"昨天打板的人今天没被埋"——短线资金的接力意愿是真实的，不是一日游。**

**但要注意：** 涨停 86 家 < 昨日 122 家，**涨停总数在缩**。所以准确表述是：**接力还在（昨日涨停股今日 81% 上涨），但新开板在减少（122 → 86）。这是"情绪维持、边际减弱"的组合。**

### 2.7 第 6 条：两融未决——收盘版并没有多一天的数据

必须说清楚：**收盘版相对午间版，两融数据没有任何更新。** 11-05 的两融要到 11-06 才披露，所以判据 #7 用的仍是 11-04 的数据（融资余额 22,643.55 亿、+13.29 亿）。

**这不是遗漏，这是制度决定的。** 但读者容易误以为"收盘版 = 数据更全"，所以这一条要写在明面上：**收盘版多的是"当日价格的完整路径"和"当日成交结构的完整数据"，不是"多一天的资金数据"。**

**顺带修正一个数字**：午间版写"融资余额 +13.18 亿"，本期按沪深两市合计口径核准为 **+13.29 亿**（上交所 +9.85 亿、深交所 +3.44 亿）。**这 0.11 亿的差异来自数据源口径，不影响任何结论，但既然发现了就要改。**

### 3.2 折算的风险：昨天证明过，1.5% 的误差能改一个仓位档

上一期（11-04 收盘版）用同样的折算方法，结果把沪深300 的 PE 高估了 1.56%（13.8680 vs 官方 13.6546），ERP 被压低 0.11pp、z 被压低 0.09σ，**恰好跨过 μ，触发了"底仓 9% → 6%"的降档**。

本期仍在用折算，所以要主动做敏感性：**如果 11-05 官方 PE 比折算值低 1.5%，z 会怎么变？**

```
基准：PE 13.6948，y10 1.591，μ 5.68，σ 1.19  →  ERP 5.71%，z +0.03σ
若官方 PE 低 1.5%（13.4894）：ERP 5.82%，z +0.12σ
若官方 PE 高 1.5%（13.9002）：ERP 5.60%，z −0.07σ
```

**结论：±1.5% 的折算误差，会让 z 在 −0.07σ 到 +0.12σ 之间摆动。** 这个区间**跨越了 μ（0σ），但没有跨越 ±1σ 的档位边界**——除了"< μ 就降档"这一条特别脆的规则。

**所以本期必须说一句丑话**：**如果 11-05 官方 PE 落在 13.90 以上，底仓目标就要退回 6%。** 我现在给 9%，是基于折算值；**这个 9% 的置信度，只有 ±1.5% 的 PE 精度那么高。** 上一期就是在这里翻的车，本期不再假装它很稳。

**方法论上这叫"报告离边界多远"**：z = +0.03σ，距 0 只有 0.03σ，而口径噪声有 0.10σ。**信号小于噪声。所以正确的动作不是"选档位下注"，而是"维持现状不动"。**

### 3.3 三个参照系：这次仍然撕裂，但撕裂的位置变了

| 参照系 | 沪深300 | 创业板指 | 结论 |
|---|---|---|---|
| **自身历史分位** | PE 5 年 **76.88%**（偏贵）；PB 5 年 37.82%（偏便宜） | PE 5 年 **17.75%**（便宜）；PB 5 年 28.16%（便宜） | 沪深300 撕裂、创业板一致偏便宜 |
| **相对无风险利率** | ERP **5.71%**、z **+0.03σ**（正好公允） | 股息率 1.212% **低于** 10Y 1.591%（**−0.379pp**） | 沪深300 公允、创业板无类固收属性 |
| **横截面比价** | 创业板 PE / 沪深300 PE = **2.117 倍** | — | 比价回到历史中位偏上 |

**沪深300 的撕裂依旧是核心矛盾**：PE 分位 76.88% 说"偏贵"，PB 分位 37.82% 说"偏便宜"，ERP 说"正好公允"。**三个参照系，三个答案。**

**这个撕裂不是数据错误，它就是信息本身。** PE 高而 PB 低，只有一个解释：**ROE 在下降**（因为 PE = PB / ROE，PE 的分母 E 掉得比 PB 的分母 B 快）。下一节反推它。

**创业板指的三个参照系是一致的**：PE 分位 17.75%（便宜）、PB 分位 28.16%（便宜）、股息率低于国债 0.379pp（不能当债券买）。**结论：它是"成长股的便宜"，不是"类固收的便宜"。** 这两者的买入理由完全不同——前者要靠盈利增长兑现，后者只要利差存在就成立。

### 3.4 PE-PB-ROE 三角反推：便宜的是 PB，坏掉的是 ROE

由 `ROE = PB / PE` 反推隐含 ROE（同一时点、同一口径）：

| 指数 | PE 11-04 官方 | PB 11-04 官方 | **隐含 ROE = PB/PE** | 读法 |
|---|---:|---:|---:|---|
| 上证50 | 11.8200 | 1.2327 | **10.43%** | 蓝筹正常水平 |
| 沪深300 | 13.6546 | 1.3451 | **9.85%** | 略低于 10%，"低增长 + 稳分红" |
| 深证成指 | 25.4721 | 2.2880 | **8.98%** | 比沪深300 低，却贵 1.88 倍 |
| 创业板指 | 28.7393 | 4.0324 | **14.03%** | 成长股该有的水平 |
| 科创50 | 94.4536 | 6.0616 | **6.42%** | **低于沪深300 3.43pp，却贵 7.01 倍** |
| 上证指数 | 16.1425 | 1.4117 | **8.75%** | 全市场口径，被亏损股拖累 |

**为什么这张表用 11-04 官方 PE/PB、而不是收盘折算值**：ROE = PB/PE 是一个**比值**，PE 与 PB 同比例折算时比值不变，所以用官方值与用折算值的结果相同。**结构值不受折算污染，水平值（PE、ERP、z）才受污染**——这个区别在 3.5 末段还会再用一次。

**这张表里最值得看的是两行：科创50 和上证指数。**

**科创50：ROE 6.42%，PE 96.04 倍（收盘折算）。** 你付 96 倍的价格，买一门 ROE 只有 6.42% 的生意——**比沪深300 的生意差 3.43 个百分点，价格却是它的 7.01 倍。** 今天它涨了 1.68%，**涨的是倍数，不是 ROE**（ROE 一天不会变）。这就是"贵得不一样"的精确含义：**创业板的 29 倍对应 14.03% 的 ROE，是合理的；科创50 的 96 倍对应 6.42% 的 ROE，只能解释为"在为未来 ROE 翻几倍付钱"。**

**上证指数：ROE 8.75%，比沪深300 低 1.10pp。** 为什么？因为上证有 **612 家亏损成分股**（占 2,233 家的 27.4%），而沪深300 只有 **25 家**（占 8.3%）。**同一个"上证 PE 16.16 倍"，里面装着一批不赚钱的公司。**

**三角反推的第二个用途：判断"PB 便宜"是盈利恶化还是净资产扩张。** 创业板 PB 分位 28.16%（便宜）、PE 分位 17.75%（更便宜）。**两者都便宜，但 PE 比 PB 更便宜，说明 ROE 在上升**（PE = PB/ROE，PE 相对 PB 更低 = ROE 更高）。反推 ROE 14.03%，与三季报创业板的盈利增速方向一致。

**所以创业板的"便宜"，是估值压缩造成的，不是盈利恶化造成的。** 这个判断是第四章"纯估值杀"的独立交叉验证。

### 3.5 股息率 - 国债：唯一还有"绝对安全垫"的地方在上证50

| 标的 | 股息率(TTM) | 10Y 国债 | 利差 | 股息率 10 年分位 |
|---|---:|---:|---:|---:|
| 上证50 | **3.1899%** | 1.591% | **+1.599pp** | 56.71% |
| 沪深300 | 2.7848% | 1.591% | +1.194pp | 76.51% |
| 上证指数 | 2.3131% | 1.591% | +0.722pp | 57.50% |
| 深证成指 | 1.8049% | 1.591% | +0.214pp | 88.96% |
| 创业板指 | 1.2120% | 1.591% | **−0.379pp** | 88.59% |
| 科创50 | 0.2932% | 1.591% | **−1.298pp** | 12.80% |

**三个读数**：

1. **上证50 的 1.599pp 利差，是当前唯一"股息显著高于国债"的大类资产。** 这也是它在 10 月的下跌里抗跌的原因——**买它的理由从来不是"便宜"，是"票息比国债高 1.6 个百分点"。**
2. **创业板与科创50 的股息率低于国债**，这意味着它们**不能**用"类固收"逻辑买入。它们的估值支撑只能来自盈利增长，没有第二条腿。
3. **上证50 的股息率 10 年分位只有 56.71%**——"中性"听起来无害，但要注意：股息率分位低意味着"股息相对自身历史偏低"，也就是"价格相对股息偏贵"。**它的安全垫是相对国债的，不是相对自己的。**

**把 3.4 和 3.5 合起来，会得到一个不太舒服的结论**：**沪深300 的"便宜"是假的（PE 分位 76.88%），上证50 的"安全"是真的（利差 1.599pp），创业板的"便宜"是真的（PE 分位 17.75%），科创50 的"贵"是真的贵（96 倍 / ROE 6.42%）。**

**六个指数，四种性质。** 这就是为什么"现在能不能买"这个问题没有统一答案——**它取决于你买的是哪一个，以及你要的是票息还是增长。**

### 3.6 本章留下的张力

估值表给出的结论是分裂的：**创业板 PE 分位 17.75%（很便宜），但沪深300 的 ERP z 只有 +0.03σ（刚好公允）。**

一个说"还有很大空间"，一个说"已经到位"。**如果两个都对，那么"空间"只能在创业板内部，而不在指数层面。** 这就把问题推给了第四章：**创业板的便宜，到底是"跌出来的"，还是"盈利撑出来的"？**

## 第四章 跌幅解剖：−41.29% 里 120.7% 是估值

### 4.1 对数分解：从 6 月高点到今天收盘

用创业板指自身的 PE 与隐含 E 做分解（不引入外部盈利口径），起点为 6 月 23 日高点 4,371.99（PE 55.145），终点为今天收盘 2,566.80（PE 28.9886）：

| 分解项 | 起点 | 终点 | 变动幅度 | 对数贡献 | 占总变动比重 |
|---|---:|---:|---:|---:|---:|
| PE(TTM) | 55.145 | 28.989 | **−47.43%** | −0.6431 | **+120.7%** |
| 隐含 E | 79.28 | 88.55 | **+11.68%** | +0.1105 | **−20.7%** |
| 点位 | 4,371.99 | 2,566.80 | **−41.29%** | −0.5326 | 100.0% |

**校验**：估值贡献 +120.7% + 盈利贡献 −20.7% = **100.0%**；对数残差 **0.00e+00**。

**读法**：创业板指从高点跌了 41.29%，其中**估值压缩贡献了 120.7%，盈利增长反向抵减了 20.7%**。也就是说，**如果盈利没有增长，指数应该跌 47.4%；是盈利把跌幅从 47.4% 拉回到了 41.3%。**

**这是"纯估值杀"的干净形态**：分母（E）在涨，分子（P）在跌，跌的全是倍数。

**与午间的差别只有一个小数位**：午间算的是 −41.07%（终点 2,576.28），收盘是 −41.29%（终点 2,566.80）。**0.22 个百分点的差别，全部来自下午那 0.37% 的回落。**

### 4.2 今日全天：100% 是估值

必须把这句话说精确：**这一整天，E 没有变，变的只有 PE。**

因为折算 PE 是"11-04 官方 PE × 涨跌幅"算出来的，**折算公式本身就把"E 不变"写死了**。所以：

```
今日点位变动 = +0.87%（创业板指）
今日 PE 变动 = +0.87%（28.9886 / 28.7393 − 1）
今日 E 变动  = 0.00%
```

**这不是一个"发现"，而是一个"定义"——必须诚实地这么说。** 今天没有财报、没有盈利预告，E 在物理上不可能变化。所以"今天涨跌 100% 由估值贡献"这句话，**是恒等式，不是分析结论**。

**但它仍然有用**：它提醒你，**今天赚的钱，全部是"别人愿意付的倍数"变化，不是"公司赚的钱"变化。** 倍数可以在一天内给你，也可以在一天内拿走；盈利不会。

**今天就是最好的例子**：上午你的账面上多了 1.24%，收盘只剩 0.87%。**那 0.37% 从来没有属于过你，它只是一个报价。**

### 4.3 一个独立口径的对照：三季报的盈利方向

为了避免"自证"，用三季报做独立对照：

- 创业板已披露三季报的 869 家公司，合计营收 **2.49 万亿元（同比 +27.14%）**，合计净利 **1,849.78 亿元（同比 +18.02%）**；Q3 单季营收环比 **+7.46%**、净利环比 **+4.78%**。
- 双创（创业板 + 科创板）归母净利增速 **+83.7%**（沿用上一期口径，本期无更新）。
- **创业板指 100 家成分股中，亏损 12 家（12%）**，与上一期持平。

**两个口径（指数 PE 隐含 E vs 三季报实际盈利）指向同一个方向：盈利在增长，且增速不低。** 这与"纯估值杀"的判定一致。

**但必须说清一个陷阱**：跌幅分解会**系统性低估逻辑杀**，因为分母下修是滞后的。如果未来某个季度盈利转负，今天这个"120.7% 是估值"的结论会立刻变得乐观。**分解只证明"已实现层"的干净程度，不证明"前瞻层"的安全。**

### 4.4 本章留下的张力

已实现层的结论很干净：跌的是倍数，不是盈利。

但前瞻层的问题没解决：**盈利增速 +18% 到 +84% 的这个区间，能维持多久？** 如果 2027 年的增速掉到 +8%，那么现在的 29.0 倍 PE 对应的是 26.84 倍的前瞻 PE——**并不便宜**（见 6.5 的隐含预期反推）。

## 第六章 情景与赔率：从 0.98 回到 1.00，等于没有优势

### 6.1 三情景：参数未变，只有当前价变了

情景参数沿用 11-04 收盘版（A 加速 30% / B 维持 45% / C 放缓 25%），**未因 TTM 盈利滚动更新而重估**——这是保守处理，列入缺口。

| 情景 | 概率 | 悲观 | 中枢 | 乐观 | 中枢相对当前 | 中枢隐含 PE |
|---|---:|---:|---:|---:|---:|---:|
| A 加速（g = +20%） | 30% | 3,059 | 3,388 | 3,717 | **+31.99%** | ~32 |
| B 维持（g = +8%） | 45% | 2,249 | 2,478 | 2,707 | **−3.46%** | ~26 |
| C 放缓（g = −10%） | 25% | 1,520 | 1,747 | 1,974 | **−31.94%** | ~22 |

**A/B/C 是三个互斥的世界，不是三个价格区间。** 每个情景的触发条件是：A = AI 算力订单延续 + 现金流验证通过；B = 增速回落至 8%、估值维持；C = 盈利转负 + 估值压缩。

### 6.2 概率加权：期望点位一分没变

```
概率加权期望 = 0.30×3,388 + 0.45×2,478 + 0.25×1,747 = 2,568.25
当前（收盘）= 2,566.80
期望收益 = 2,568.25 / 2,566.80 − 1 = +0.06%
```

**注意这个数的性质：展望点位一分没变（仍是 2,568.25），是价格回来了。** 昨天 +0.92%，上午 −0.31%，收盘 +0.06%。**一天走完，围绕同一个靶子上下摆动了 1.2 个百分点，最后停在离靶心 1.45 点的地方——0.06% 的期望，等于零。**

**"零期望"的准确读法**：不是"没有风险"，是"**风险与收益正好抵消**"。在这种状态下，任何仓位调整都只是增加交易成本，不改变期望。**这就是"不动"的数学依据。**

### 6.3 赔率双口径：中枢回到 1.00，尾部 1.10

| 口径 | 上方空间 | 下方空间 | 赔率 | 含义 |
|---|---:|---:|---:|---|
| **中枢口径** | 821.20 | 819.80 | **1.00 : 1** | 期望上下空间比——**正好相等** |
| **尾部口径** | 1,150.20 | 1,046.80 | **1.10 : 1** | 极端情形盈亏比——略偏正 |

**两个口径的差异必须解释**：中枢口径是"概率加权后的上下空间"，尾部口径是"最好与最坏情形的极值比"。

- 中枢 1.00:1 说明：**按概率加权，向上和向下的空间几乎完全相等（差 1.4 点）。**
- 尾部 1.10:1 说明：**如果只看极端情形，向上的空间（A 乐观 3,717）比向下（C 悲观 1,520）多 103 点。**

**为什么尾部比中枢好看？因为 A 情景的乐观值（3,717）离中枢（3,388）有 329 点，而 C 情景的悲观值（1,520）离中枢（1,747）只有 227 点。** 换句话说：**乐观情景的"想象空间"更大，悲观情景的"下坠空间"更收敛。** 这是典型的"右偏分布"——**赔率的中枢口径更能反映真实期望，尾部口径容易让人过度乐观。**

**上一期是 1.06:1，午间是 0.98:1，收盘是 1.00:1。** 三个数在 1 附近来回摆动——**这本身就是结论：这个市场的赔率，现在没有方向。**

### 6.4 敏感性矩阵：四个角，四种命运

5×5 矩阵（增速 × PE），整表由 `calc.py sensitivity` 产出，对角线锚定当前 2,566.80：

| 增速 \ PE | 20 倍 | 24 倍 | **28.99 倍** | 32 倍 | 39 倍 |
|---|---:|---:|---:|---:|---:|
| **−20%** | 1,417 (−44.81%) | 1,700 (−33.77%) | 2,053 (−20.00%) | 2,267 (−11.69%) | **2,763 (+7.63%)** |
| −10% | 1,594 (−37.91%) | 1,913 (−25.49%) | 2,310 (−10.00%) | 2,550 (−0.65%) | 3,108 (+21.08%) |
| **0%** | 1,771 (−31.01%) | 2,125 (−17.21%) | **2,567 (0.00%)** | 2,833 (+10.39%) | 3,453 (+34.54%) |
| +12% | 1,983 (−22.73%) | 2,380 (−7.27%) | 2,875 (+12.00%) | 3,173 (+23.63%) | 3,868 (+50.68%) |
| **+20%** | **2,125 (−17.21%)** | 2,550 (−0.65%) | 3,080 (+20.00%) | 3,400 (+32.47%) | **4,144 (+61.44%)** |

**四个角，四种命运：**

- **右上（+20% 增速 × 39 倍 = 4,144，+61.44%）**：**乐观空间的来源**。但它要求"盈利超预期 + 估值扩张"同时发生，概率最低。
- **左下（−20% × 20 倍 = 1,417，−44.81%）**：**真正的尾部**。盈利下滑与估值压缩同时发生，这是最坏的世界。
- **左上（−20% × 39 倍 = 2,763，+7.63%）**：**缓冲来自估值**。盈利崩了 20%，但只要估值撑在 39 倍，居然还能涨 7.6%。**这一格是全部幻觉的来源**——它告诉你"即使基本面差，只要市场愿意给倍数，你还能赚钱"。**这一格也是本矩阵最脆弱的假设。**
- **右下（+20% × 20 倍 = 2,125，−17.21%）**：**"好公司不涨"**。盈利超预期 20%，但估值被压到 20 倍，你亏 17.2%。**这是"盈利兑现但估值杀"的典型，也是成长股最常见的亏钱方式。**

**四角连起来的结论**：**这个矩阵的分布是"右偏但左尾厚"**——向上有 61% 的空间（需要两个条件同时成立），向下有 45% 的空间（只需要盈利下滑一个条件）。**赔率 1.00:1 的根源就在这里：概率上中间值略占优，但尾部更厚。**

**一个重要观察**：把矩阵的两条对角线读一遍——右上 4,144 与左下 1,417 的比是 **2.93:1**，但概率加权后只有 1.00:1。**这说明"极值赔率"极具欺骗性：它让你觉得"亏 45% 换赚 61% 很划算"，但概率分布把这个优势抹平了。**

### 6.5 隐含预期反推：市场在定价"零增长"

```
若 PE 维持 28.9886 倍不变，当前点位 2,566.80 隐含的盈利增速 = 0.0%
若盈利增速 +8%，合理 PE = 28.9886 / 1.08 = 26.84 倍
→ 当前 PE 比它高 8.00%（反过来，合理 PE 比当前低 7.41%），市场在定价"估值下移（de-rating）"
```

**这句话的读法是**：如果市场认为盈利能增 8%，那么合理的 PE 应该是 26.84 倍（对应点位约 2,377），而不是 28.99 倍。**当前价格比"8% 增速下的合理价"高出 8.00%。**

**市场在定价哪个情景？** 答案是：**它既不定价 A（+20%），也不定价 C（−10%），它定价的是 B（+8%）但给了一个偏高的倍数。** 换句话说：**盈利预期是"维持"，估值给的是"加速"的价钱。这中间的缺口，就是赔率为 1 而不是 2 的原因。**

### 6.6 三个最脆弱的假设（按优先级）

| 优先级 | 假设 | 被打破的后果 |
|---|---|---|
| **1** | **情景概率（30/45/25）是主观赋值，未经统计检验** | 若把 A 概率从 30% 降到 20%、C 从 25% 升到 35%，期望点位降到约 2,470，期望收益 −3.8% |
| **2** | **情景点位沿用上期，未因 TTM 盈利滚动上修** | 若按官方 E 上修 1.5% 同比例上修情景点位，期望点位升至约 2,607，期望收益 +1.6%——**结论会翻正** |
| **3** | **PE 区间上限 39 倍、下限 20 倍是人设边界** | 若估值扩张到 45 倍，右上角变 4,781；若压缩到 17 倍，左下角变 1,204 |

**第二个假设最危险，必须单独说**：本期用官方序列发现 E 被低估了 1.5%（沪深300）。**如果 E 系统性上修，那么情景点位也应该上修，期望收益就会从 +0.06% 变成 +1.6%。** 我没有上修，是出于"不悄悄改历史结论"的纪律——**但这个保守选择本身，可能让本期结论偏空。这是必须承认的偏差方向。**

**必须说出偏差方向，而不是说"我的结论很稳"。** 一个不知道自己在哪边错的判断，和一个知道自己在哪边错的判断，价值完全不同。

### 7.1 为什么不能画"估值分位 × 资金方向"的 2×2 象限

### 7.5 冷门的两个意思：本期唯一的冷门，不便宜

这是本期最需要拆开的一处，因为**混用会直接买错**。

| | **资金冷**（在流出/无人问津） | **资金不冷** |
|---|---|---|
| **估值冷**（分位低） | **真·冷门**：跌幅与估值同时到位 → 唯一有赔率的格 | 低估但被忽视，需查基本面瑕疵 |
| **估值不冷**（分位高） | **假·冷门**：跌得多但依然贵 → 最危险的误判 | 热门且贵 → 拥挤 |

**本期能确定的是"资金冷"，能"部分确定"的是"估值不冷"，不能确定的是"估值冷"。**

- **资金冷（现象）**：**国有大型银行**——今日 −0.72%（12 个板块里唯一负）、5 日 −4.38%（唯一负）、60 日 +14.55%、年初至今 +7.90%。**它是过去两个月最强的板块之一，现在在回落。**
- **估值冷（资格）**：**无法直接判定**（缺板块分位）。但可以用上证50 作**代理**（银行是其第一权重）：**PE 5 年分位 94.64%**，接近五年最贵的 5%。
- **所以结论是**：**国有大型银行不是"冷门"，是"拥挤之后的退潮"。** 它不便宜（代理分位 94.64%），涨了很多（60 日 +14.55%），现在在被卖。**这属于"热门且贵 → 退潮"，不属于任何一格的候选池。**

**一句话规则照抄方法论**：**资金冷是现象，估值冷是资格。** 只有估值冷才进候选池；资金冷只是"为什么现在能以便宜价买到"的解释。

**本期候选池：空。** 但这次的"空"与午间的"空"含义不同——午间是"数据不允许判定"，本期是"**唯一冷门经代理口径检验后，不便宜**"。**前者是能力问题，后者是结论。这是一个实质性的进步。**

### 7.6 一个必须点破的错觉：跌得多 ≠ 便宜

今天涨幅第一的光伏设备 +6.23%，年初至今 **−28.53%**。很多人看到这个组合，第一反应是"跌了这么多，还有很大空间"。

**但这个推理有一个致命的漏洞：跌幅是价格的函数，便宜是"价格 ÷ 盈利"的函数。**

```
PE = P / E
若 P 跌 28.53%，但 E 也跌 30%，则 PE 上升 2.1%
```

**一个跌了 28.53% 的板块，如果盈利跌得更多，它比跌之前更贵。**

**这就是"以跌幅代便宜"的陷阱**，也是第七章最值得记住的一句：**跌幅告诉你"过去发生了什么"，估值告诉你"现在贵不贵"。两者不是同一件事，把它们混为一谈，是散户最常见的亏钱方式。**

**本期无法验证光伏的 E 是否也在跌**（板块级盈利数据未取得）——**所以本报告对光伏的判断只能到"盈利修复信号出现，但未验证"为止，不能到"便宜"。**

### 7.7 本章留下的张力

板块层面能确认三件事：**① 午后从"跌深反弹"换棒到"趋势延续"；② 传媒链是唯一三尺度同向的线索；③ 唯一的冷门（银行）不便宜，候选池仍空。**

那么问题落到个股层面：**在这批"三尺度同向"的板块里，哪些公司是"业绩在、估值被杀"，哪些是"估值靠叙事"？** 这决定了两类完全不同的操作。

## 第八章 龙头三分类：收盘给出三个不同信号

判别只需一问：**这个变化，是分母（盈利）变了，还是倍数（估值）变了？**

- 分母变了 → 逻辑杀，任何反弹都是逃命。
- 倍数变了 → 估值杀，跌到位就有价值。
- **两类龙头的抄底逻辑不同，绝不能用同一套话术。**

### 8.1 A 类：业绩在、估值被重定价——收涨，但从高点回吐一半

**特征**：净利仍高增，PE 从高位压到中位。**跌幅的含义是"倍数切换"，不是"盈利崩塌"。**

**代表**：半导体设备、光伏主链。

**今天的收盘证据（这是新增的一层）**：

| 标的 | 收盘 | 涨跌幅 | 当日最高 | 最高时涨幅 | 从高点回吐 | 振幅 |
|---|---:|---:|---:|---:|---:|---:|
| 中微公司 | 254.00 | **+5.83%** | 265.00 | +10.41% | **−4.15%** | 12.50% |
| 中科飞测 | 269.00 | **+9.02%** | 295.80 | +19.88% | **−9.06%** | 18.84% |
| 拓荆科技 | 502.84 | **+3.09%** | 528.35 | +8.32% | **−4.83%** | 9.08% |
| 阳光电源 | 85.14 | **+4.89%** | 91.30 | +12.48% | **−6.75%** | 13.76% |
| 宁德时代 | 264.06 | **+4.42%** | 272.19 | +7.64% | **−2.99%** | 6.43% |

**这张表最重要的一列是"从高点回吐"，不是"涨跌幅"。**

五只票全部收涨，但**全部从当日最高点回吐了 3% 到 9%**。中科飞测盘中一度 +19.88%，收 +9.02%，**一天之内把一半的涨幅还回去了**。

**这说明什么？** 说明**在这个位置，卖方比买方更坚决**。A 类公司的"估值修复"叙事没有被证伪（盈利还在，倍数还低），但**修复的过程遇到了实实在在的抛压**。

**该等什么**：**等现金流验证**（C2 类条件）——算力链/光伏链权重股的「经营现金流 / 净利」连续 1 季 ≥ 0.6。**不是等反弹。**

**不该等什么**：**不该等"跌够了"这个信号。** A 类公司的跌幅可以很大（−40% 到 −60%），但"跌够了"不是一个可观测变量；**能观测的是现金流，不是跌幅**。今天的"从高点回吐 4%–9%"，也不该被当成"跌够了"——**它只是"今天买在高点的人被套了"，和"是否便宜"无关。**

### 8.2 B 类：估值靠叙事——融资买得最多，股价收跌

**特征**：PE 极高、无现金流锚。**跌幅的含义是"泡沫释放"。**

**代表**：科创50 里 PE 与 ROE 严重背离的部分标的（指数 PE 96.04 倍 / ROE 6.42%）。

**今天最有力的一个证据，不是指数的涨跌幅，而是一组背离**：

| 指标 | 数值 | 含义 |
|---|---|---|
| 寒武纪涨跌幅 | **−0.31%** | 收绿 |
| 当日最高涨幅 | +4.04%（881.88 元） | 盘中曾涨 4% |
| 收盘 | 845.00 元 | 从高点回吐 4.18% |
| **全市场融资净买入排名** | **第 1 名，+6.53 亿元** | 借钱买它的人最多 |
| 科创50 指数 | +1.68% | 指数在涨 |

**"全市场融资净买入第一"和"股价收跌"同时发生**——这是本期最值得写进教科书的一组数据。

**它说明三件事**：

1. **融资盘是"意愿"的度量，不是"结果"的度量。** 有人愿意付利息赌它涨，不代表它会涨。**借款是买入的前置动作，不是买入的成功。**
2. **出货的量大于接货的量。** 融资净买入 6.53 亿，股价还跌 0.31%——**意味着有超过 6.53 亿的现货在卖。**
3. **叙事票的定价权，已经从"讲故事的人"转移到"兑现的人"手里。** 科创50 盘中最高 +5.03%、收 +1.68%，回吐 3.35pp——**这个回吐幅度是全市场最大的。**

**该等什么**：**等 ROE 抬升的证据**（不是等股价）。具体是：指数 ROE 从 6.42% 升到 8% 以上，或前瞻 PE 从 47.98 倍回落到 35 倍以下。

**不该等什么**：**不该等"政策底"或"情绪底"，更不该等"融资盘回补"。** B 类的底部由情绪决定，**不进点位框架**——任何"跌到 XX 点就买"的说法，对 B 类都是伪精确。**而"融资盘会托底"这个想法，今天已经被证伪了：融资净买入第一的票，照样收跌。**

### 8.3 C 类：资金再配置型防御——走平，但银行在跌

**特征**：逆势上涨、股息率高。**上涨=配置行为，不是盈利改善。**

**代表**：上证50（股息率 3.19%、与国债利差 +1.599pp）。

**今天的收盘证据有一处微妙的变化**：上证50 收 **+0.09%**，午间是 **−0.01%**，**从"唯一没涨"变成了"红盘但最弱"**。而它的第一权重行业——**国有大型银行 −0.72%，是 12 个板块里唯一收跌的。**

**这两件事放在一起，含义是**：**上证50 的红，不是银行撑起来的。** 银行在跌，上证50 还在微涨，说明**有其他成分（保险、白酒、能源）在补位**。

**所以"防御端被抛弃"这个说法不成立——准确的表述是"防御端内部在换手"**：钱从银行（涨了 14.55% 的、贵的）流向同属防御但滞涨的品种。**这是"防御板块内部的高低切换"，不是"资金离开防御"。**

**该等什么**：**等利差收敛**。具体是：股息率被买到贴近 10Y 国债（利差从 +1.599pp 收敛到 +1.0pp 以内），那时配置价值消失。

**不该等什么**：**不该等它"补涨"。** C 类的天花板就是股息-国债利差，**利差消失即退出**，它不会因为"成长涨了"而跟着涨。**也不该把"银行下跌"当成"防御失效"——它只是"防御内部换了个位置"。**

### 8.4 二线不要当"更便宜"

同一产业链上的二线弹性更大——跌得快、反弹也快，但它**不具备独立逻辑**。用"二线跌得更多"证明"二线更便宜"，是**把 β 当成 α**。

**本期的一个具体例子**：能源金属今日 +5.35%，但 60 日 −26.09%、年初至今 −41.26%，是 12 个板块里最弱的。**它涨得猛，是因为它跌得深（高 β），不是因为它变好了（无 α）。**

### 8.5 三类的收盘对照表

| | A 类（设备/光伏） | B 类（叙事/算力） | C 类（防御/红利） |
|---|---|---|---|
| 今日表现 | +3.09% ~ +9.02% | 指数 +1.68%，龙头 −0.31% | 上证50 +0.09%，银行 −0.72% |
| 从高点回吐 | 4% ~ 9% | 4% ~ 3.35pp（指数） | 0.06%（上证50 最高 2,813.90） |
| 定价主导 | 盈利修复预期 | 情绪 + 杠杆意愿 | 票息 + 配置需求 |
| 该等什么 | 现金流验证 | ROE 抬升 | 利差收敛 |
| 不该等什么 | "跌够了" | "政策底/情绪底/融资回补" | "补涨" |
| 本期动作 | 不动 | 不动 | 不动 |

**三类龙头的"该等什么"完全不同：A 等现金流、B 等 ROE、C 等利差收敛。但这三条都不支持"今天买"。**

**"不动"不是懒，是三种等待都对，所以没有理由动。**

### 8.6 本章留下的张力

三类龙头的信号完全不同：A 收涨但回吐、B 收跌但被融资抢、C 走平但内部换手。**三种信号互相矛盾，说明市场没有统一的方向。**

**那么，在什么条件下才该动手？** 这需要一套可执行的仓位规则，而不是三个"等"字。

## 第九章 双尺度与操作：短期不动，长期不动

### 9.1 先回答命题

**命题**：2026 年 11 月 5 日的完整一天，是否让"可以加仓"这件事更接近成立？

1. **期望收益回到零、赔率回到 1.00**：+0.92% → −0.31% → **+0.06%**；赔率 1.06 → 0.98 → **1.00**。**一天走完，回到了起点附近，但没有回到"优势"区间。**
2. **价格仍在公允价上**：沪深300 ERP z = **+0.03σ**，距 μ 点位（4,131）只有 **−0.43%**。**"便宜"这个买入理由，今天全天都没有出现过。**

### 9.3 底仓：目标 9%，本期不动

**规则值**：沪深300 ERP **5.71%**、z = **+0.03σ** → 落在 **"0 ~ +1σ"** 档 → 底仓 **9%**。

| ERP 的 σ 位置 | ERP 水平 | 底仓 | 对应沪深300 点位 |
|---|---:|---:|---:|
| ≥ +1.5σ | ≥ 7.46% | 15% | ≤ 3,317 |
| +1σ ~ +1.5σ | 6.87%–7.46% | 12% | 3,317–3,550 |
| **0 ~ +1σ** | **5.68%–6.87%** | **9%（当前 5.71%，+0.03σ）** | **3,550–4,131** |
| < μ | < 5.68% | 6% | > 4,131 |
| 股息率 < 10Y 国债 | — | 0%（逻辑失效） | — |

**关键的一句**：当前沪深300 是 **4,113.41**，距离"跌破 μ"的边界 **4,131** 只剩 **+0.43%**。**只要再涨 0.43%，z 就会重新跌破 μ，目标档位就会回到 6%。**

**这就是"边界"的含义**：不是"9% 很安全"，而是"9% 只在一条不到 600 点的窄带里成立（3,550–4,131），而当前价距离上沿只有 0.43%"。

**本期动作：不动。** 理由：

1. 上期目标 6% 从未执行（原文"减仓不立即执行"），实际持仓 9%；
2. 本期目标回到 9%，与实际持仓一致 → **不需要任何交易**；
3. **在边界上，最小的动作就是最正确的动作。**

**必须声明的设计判断**：如果明天涨过 4,131，我会把目标写回 6%，但**仍然不执行减仓**，而是等"连续 3 个交易日 ERP < μ"。这是上期就定下的规则，本期不变。

### 9.5 风险预算：当前 10%，上限 22%

```
σ_p = sqrt((1.5%×0.36)² + (9%×0.39)² + 2×1.5%×9%×0.36×0.39×0.86)
    = 3.98%
等效单一标的仓位 = 11.1%

上限：w1 = 12%、w2 = 10% → σ_p = 7.93% → 等效 22.0%
```

**当前合计名义仓位 10%（创业板 1.5% + 沪深300 9%），距上限 22% 还有 12pp 空间。空间很大，但空间大不等于该用。**

```
按实测波动率重算（w1=1.5%、w2=9%，ρ=0.86）：
σ_p = sqrt((0.015×0.4688)² + (0.09×0.1697)² + 2×0.015×0.09×0.4688×0.1697×0.86)
    = 2.16%
```

**实测波动率算出来的组合风险只有 2.16%，比用假设值算的 3.98% 低 45.7%。** 原因是我在原始参数里把创业板波动率设成了 36%（一个跨周期的中枢值），而**近 20 日的实测值是 46.88%**——**也就是说，短期风险被低估了，长期风险被高估了。**

**这个差异必须说明白，否则 9.5 的数字会误导人**：**3.98% 是"跨周期口径"，2.16% 是"近 20 日口径"。** 前者用于定仓位上限（保守），后者用于看当前的实际暴露（乐观）。**两个都给，不择优。**

### 9.6 短期与长期：分两栏，禁止混写

**短期（1–4 周）：只回答"动不动手"。**

4. **如果明天缩量下跌**，说明今天午后的缩量是"没人接"而不是"没人卖"——**那时候赔率会在更低的位置重新变好，才轮到 P0 说话。**

**长期（1–3 年）：只回答"买什么、买多少"。**

1. **双轨结构不变**：底仓沪深300（目标 9%）+ 弹性仓创业板（上限 10%，当前 1.5%），合计硬上限 22%。
2. **长期主线不是"AI 硬件"，是"现金流转化验证者"。** C2 是唯一硬约束，板块会轮动（今天从硬资产换到软内容就是一次轮动），这个条件不会。
3. **防御端的角色是压波动，不是赚超额。** 上证50 股息率 3.19%、与国债利差 +1.599pp。**它今天 +0.09%，在科创50 涨 1.68% 的日子里落后——这正是它的功能。**
4. **最大的风险是"便宜凭空消失"**：亏损面扩张（创业板 12 家）会抬升 PE，让"17.75% 分位"这个便宜变成假的。
5. **到点不看条件 = 不动手。** 价格档只是资格门槛，不是加仓指令。

### 10.4 最后一句实话

今天最重要的结论不是"涨了"或"跌了"，而是：

**变化的只有报价。报价是别人愿意付的价钱，它不是价值，它是"当下这一刻的共识"。**

**上午的共识是乐观的（+1.24%），午后的共识是谨慎的（−0.37%），收盘的共识是"就这样吧"（+0.06% 的期望）。**

**这三个共识，没有一个是"便宜"。这就是今天什么都没发生的原因，也是今天最值得记录的事。**
