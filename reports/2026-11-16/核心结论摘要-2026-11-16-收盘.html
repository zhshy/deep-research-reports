核心结论三句话 + 四个数

本期的增量不是「再讲一遍下跌」，是「用收盘价把上午那三条判断重新判一次，并说清哪几条作废」。

第一句：跌停 68 家——午间的「定向爆破」叙事被整体推翻。 上午跌停 14 家、上涨占比 32.03%、三只光模块解释 61.5% 的跌幅；收盘跌停 68 家（1.217%，越过 1.0% 踩踏阈值）、 上涨占比 20.34%（1,136 家）、三只解释 52.7%。 集中度下降而痛苦扩散，这是「全面杀跌」，不是「定向爆破」。 最硬的证据：其余 51.16% 权重（午间同口径）的平均跌幅，从上午 −2.11% 扩大到 −4.45%，比指数本身（−4.37%）还大——「其余的股票」跌得比平均数更狠。
第二句：所以 P0 这次是「真破」，不是「被绑架」——而加仓的三条条件，收盘只满足两条。 收盘 2,320.02 低于 P0 达 −3.33%（上午 −1.28%）；赔率升到 1.93 : 1（① 满足）； 但 跌停 68 家远超「≤20 家」（③ 被推翻），且 −4.37% < −3% 触发 ④。 结论：不执行。弹性仓停在 1.5%，合计维持 10.5%。 这不是拖延——这是 11-13 自己写好的证伪条件，今天只兑现了一半，而一半不放行。
第三句：八项判据从 +0.100 归零到 +0.000，九期最低。 #7（杠杆，权重 20%）连续第二日记 0：官方 11-13 仍未发布，替代口径 22,497.85 亿破线，折算后 22,572.77 亿又在线之上，红线正好落在两个口径的缝里。 #8（政策对冲，权重 10%）从 +1 掉到 0：今日央行 OMO 净回笼 2,040 亿。 已实现层 +0.200、前瞻层 −0.200，两层同时为真，总和为零。

冷门之二 · 估值冷：仍然找不到

这个格子是空的。原因不是「没有便宜板块」，而是数据源不提供板块级估值分位序列——任何「某板块估值处于低位」的说法在本期都不可验证。 本期唯一能拿出的估值冷证据是指数级的：创业板指 PE 分位 12.46%、PB 分位 23.27%，六个指数里唯一双低。 它只构成「这个指数整体便宜」，不构成「某板块便宜」——两者不可混用，这正是口径降级要付的代价。

龙头点评A / B / C 三类，各给「该等什么 / 不该等什么」

分类标准预先写死，不随价格调整：A = 逻辑成立且现金流可见；B = 逻辑成立但现金流未验证；C = 逻辑有疑问。

宁德 14.46%（+1.18%，贡献 +0.1706pp）　迈瑞 2.62%（+2.73%，贡献 +0.0715pp）　温氏 2.07%（+1.33%）
迈瑞是今天权重股里涨幅最大的，且是在 4,344 家下跌的背景下完成，连续三日逆势（+1.06% → +1.40% → +2.73%）。 宁德是唯一「权重超 10% 且上涨」的标的——没有它，指数会从 −4.37% 变成 −4.54%。

C 类阳光电源 · 汇川技术

阳光 2.29%（−2.17%，连续三日下跌）　汇川 2.64%（−0.92%，连续两日跑输）
问题不是「跌」，是「失去独立性」：汇川 11-13 是 +0.64%（指数 −3.32%，强），今天 −0.92%（指数 −4.37%，只跌得少一点）——从「逆势上涨」退化成「跟随下跌」。

不该等什么不该等「跌多了会反弹」。最危险的操作是用 B 类的逻辑（便宜）买 C 类的标的（逻辑有疑问）——逻辑重定价没有「跌到位」这回事。

A 类等业绩，B 类等现金流，C 类等逻辑。三类都不等价格。 今天跌得最狠的是 B 类（−9.6% ~ −12.3%），最抗跌的是 A 类（+1.2% ~ +2.7%）——市场一整天都在做同一件事：把「未来的现金流」换成「当下的现金流」。 而且下午这个分化更极端了：A 类不仅抗跌，还在加速上涨。
